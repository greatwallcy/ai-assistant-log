## 技术要点
- GitHub REST API 可直接创建/更新文件，无需 git clone
- Classic token 比 Fine-grained token 操作更简单
- Token 用完后应及时 revoke
- API 地址: `PUT /repos/{owner}/{repo}/contents/{path}`
- SVG 用 rsvg-convert 转 PNG（1600px 宽度）
- 大文件上传需写临时文件再用 curl @filename 方式
- BMS功能测试应覆盖：电源、AFE采样/保护/均衡、MCU通讯、SOC/SOH、功率、高压、接触器、数据记录、安全测试
- 电气布线：水路全走顶，电路走地为主/厨卫走顶
- 开关控制线用绿色，双控联线用白色，不能和零线（蓝色）混淆
- 插座和开关暗盒都要预留15cm线头
