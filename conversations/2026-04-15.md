## 技术要点
- GitHub REST API 可直接创建/更新文件，无需git clone
- git commit前必须先配置user.name和user.email
- MP3421输出约1.5-2A，带不动多舵机；TPS61088可达6-7A
- SG92比SG90扭矩更大，但堵转电流也更大
- 两路电源方案：小功率MP3421给控制板，大功率TPS61088可控给舵机
- 机器狗代码核心：STM32F103C8T6 + 4路舵机（TIM3 CH1-4）+ 1路尾巴（TIM2 CH1）
- PWM输出：50Hz周期(20000us)，占空比500-2500us对应0-180度
