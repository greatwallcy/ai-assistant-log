## 技术要点
- python-docx 中 Cm() 返回的是 EMU（360000/cm），不是 twips（567/cm），设置列宽时需注意单位转换
- `w:tcW` 的 `w:type="dxa"` 表示 twips 单位
- `w:trHeight` 的 `w:hRule="auto"` vs `"exact"` 决定行高是否自动适配
- GitHub API 通过 `?ref=commit_sha` 参数可获取历史版本文件
- 列宽调整应以内容为基准，序号/电压类窄列、测试条件/备注类宽列
- 表格格式调整应小步迭代，避免过度复杂化
