## 一、材料选择与成本解析

### 1.1 电路材料

#### 电线

| 线径 | 最大电流 | 最大功率 | 用途 | 单价参考 |
|------|----------|----------|------|----------|
| 1.5mm² | 10A | 2200W | 照明回路 | 1.5-2.5 元/m |
| 2.5mm² | 16-20A | 3500-4400W | 普通插座、冰箱 | 2.5-4 元/m |
| 4mm² | 25-32A | 5500-7000W | 空调、厨房、热水器 | 4-6 元/m |
| 6mm² | 40A | 8800W | 即热热水器、中央空调 | 6-10 元/m |
| 10mm² | 60A | 13200W | 入户总线 | 10-16 元/m |

**电线类型：**
| 类型 | 说明 | 适用 |
|------|------|------|
| BV（硬线） | 单股铜芯，硬度高，连接可靠 | 固定布线（墙面/地面暗敷）|
| BVR（软线） | 多股铜芯，柔软易弯 | 弯曲多的位置、弱电 |
| RVV（护套线） | 多芯护套 | 设备连接线（不用于暗敷）|

**建议**：固定暗敷统一用 **BV 硬线**，便宜且接线可靠。

#### 线管

| 管径 | 壁厚 | 用途 | 单价参考 |
|------|------|------|----------|
| Φ16mm | 1.2-1.5mm | 照明 | 1.5-3 元/m |
| Φ20mm | 1.5mm | 普通插座 | 2-4 元/m |
| Φ25mm | 1.8-2.0mm | 空调/大功率 | 3-5 元/m |

**线管类型：**
| 类型 | 说明 | 适用 |
|------|------|------|
| PVC 阻燃管 | 最常用，便宜 | 家装通用 |
| KBG 金属管 | 强度高、防火 | 高要求场所（家装一般不用）|

#### 电线颜色标准（必须遵守）

| 颜色 | 含义 | 说明 |
|------|------|------|
| 🔴 红色 | 火线（L） | 三相：红/黄/绿 = A/B/C 相 |
| 🔵 蓝色 | 零线（N） | — |
| 🟡 黄绿双色 | 地线（PE） | **绝对不能挪用！** |
| 🟢 绿色 | 开关控制线 | 开关 L1/L2 出线到灯具 |
| ⚪ 白色 | 双控联线 | 双控开关之间互联 |

### 1.2 水路材料

#### 水管

| 类型 | 优点 | 缺点 | 单价参考 |
|------|------|------|----------|
| PPR 管 ⭐ | 热熔连接无接缝、卫生、耐压 | 不耐紫外线 | 6-15 元/m |
| PEX 管 | 柔软、耐低温 | 需专用接头 | 10-20 元/m |
| 不锈钢管 | 耐久、卫生 | 贵、施工复杂 | 30-80 元/m |

**PPR 管规格：**
| 规格 | 壁厚 | 用途 | 耐压 |
|------|------|------|------|
| S5（20×2.3mm） | 2.3mm | 冷水管 | 1.25MPa |
| S3.2（20×3.4mm） | 3.4mm | 热水管 | 2.0MPa |
| S2.5（20×4.2mm） | 4.2mm | 高温高压 | 2.5MPa |

**关键**：热水管必须用 S3.2 或更高级别，冷水管用 S5。

| ⑦ 客厅空调 | 1P+N 漏保 | 25A | 4mm² | 柜机/风管机 |
| ⑧ 主卧空调 | 1P+N 漏保 | 20A | 4mm² | 挂机 |
| ⑨ 次卧空调 | 1P+N 漏保 | 20A | 4mm² | 挂机 |
| ⑩ 电热水器 | 1P+N 漏保 | 25A | 4mm² | 如单独走线 |
| ⑪ 阳台 | 1P+N 漏保 | 16A | 2.5mm² | 洗衣机/烘干机 |
| ⑫ 弱电 | 1P 空开 | 10A | — | 路由器/光猫 |
| 预留 | — | — | — | 4-6 个空位 |

**设计原则：**
- 总开关不带漏保（避免一处漏电全屋断电，影响冰箱）
- 每个分路带漏保（动作电流 ≤30mA）
- 冰箱独立回路（出差不断电）
- 厨卫用 4mm²（小家电密集，功率大）
- 箱体选 24 位（预留扩展：智能家居、充电桩等）

## 三、施工流程图

### 3.1 水电施工总流程

```
现场定位
  │
  ├── 业主 + 工人到场，对照设计图逐个确认点位
  ├── 用粉笔/记号笔在墙面地面标注所有点位
  └── 拍照记录原始标注
  │
  ▼
开槽
  │
  ├── 弹线：墨斗弹出所有管路走向
  ├── 开槽：切割机切边 → 电镐凿除 → 修整
  ├── 原则：竖槽为主，横槽 ≤ 50cm
  └── 槽深 = 管径 + 15mm 保护层
  │
  ▼
布管
  │
  ├── 强电管：PVC 阻燃管，弯头用弯管器
  ├── 弱电管：独立走管，与强电间距 ≥ 30cm
  ├── 水管：PPR 管热熔连接，走顶优先
  ├── 管卡固定间距 ≤ 80cm
  └── 强弱电交叉处包锡箔纸
  │
  ▼
穿线
  │
  ├── 引线钢丝穿管 → 绑线 → 拉线
  ├── 每管 ≤ 3 根线，填充率 ≤ 40%
  ├── 暗盒内留 15cm 线头
  └── 配电箱内留 ≥ 50cm 线头
  │
  ▼
水路热熔
  │
  ├── PPR 管热熔连接（加热 5-7 秒，承插 3-5 秒）
  ├── 冷热水管间距 ≥ 15cm
  ├── 热水管包保温棉
  └── 冷水管在里侧（靠墙），热水管在外侧
  │
  ▼
测试
  │
  ├── 水路：打压 0.8-1.0MPa，保压 30min，压降 ≤ 0.05MPa
  └── 电路：万用表测绝缘电阻 ≥ 0.5MΩ，逐回路通电测试
  │
  ▼
封槽
  │
  ├── 槽内喷水润湿
  ├── 1:3 水泥砂浆分两次封槽
  ├── 第一次填 2/3 压实 → 第二次补平刮毛
  └── 不用石膏封槽（强度不够）
  │
  ▼
拍照存档 ⭐
  │
  └── 所有管线走向、点位位置拍照留存
      （后期打孔、挂画时对照，避免打穿管线）
```

### 3.2 电路施工子流程

```
确定回路方案
  │
  ▼
配电箱定位 → 箱体固定
  │
  ▼
各回路布管（从配电箱到各点位）
  │
  ├── 照明回路：Φ16 管 + 1.5mm² 线
  ├── 普通插座：Φ20 管 + 2.5mm² 线
  ├── 大功率（空调/厨房）：Φ25 管 + 4mm² 线
  └── 弱电：独立管 + Cat6 网线
  │
  ▼
穿线 → 接线（暗盒内接线）
  │
  ▼
配电箱内接线（总开 → 各分路漏保 → 回路接线）
  │
  ▼
逐回路测试 → 漏保测试
```

### 3.3 水路施工子流程

```
确定用水点位
  │
  ▼
弹线定位管路走向
  │
  ▼
固定管卡 → PPR 管热熔连接
  │
  ├── 冷水管 S5 级
  ├── 热水管 S3.2 级
  └── 热水管包保温棉
  │
  ▼
各用水点安装角阀/龙头接口
  │
  ▼
封堵最远端 → 打压测试
  │
  ├── 压力 0.8-1.0MPa
  ├── 保压 30 分钟
  └── 压降 ≤ 0.05MPa = 合格
  │
  ▼
排水管安装（坡度 2-3%）
  │
  ▼
拍照存档
```

## 四、施工验收与注意事项

### 4.1 电路验收标准

| 验收项 | 标准 | 检测方法 |
|--------|------|----------|
| 绝缘电阻 | ≥ 0.5MΩ | 万用表/摇表逐回路测量 |
| 回路独立性 | 各回路互不影响 | 关一个回路，其他回路正常 |
| 漏保动作 | 按测试按钮应跳闸 | 逐个漏保按测试键 |
| 接线正确 | 左零右火上地 | 验电器逐个插座检测 |
| 线径达标 | 与设计一致 | 对照图纸检查 |
| 线管固定 | 管卡间距 ≤ 80cm | 目测+测量 |
| 横槽长度 | ≤ 50cm | 测量 |
| 强弱电间距 | ≥ 30cm（平行） | 测量 |
| 交叉处理 | 包锡箔纸 | 目测 |
| 线头预留 | 暗盒 ≥ 15cm，配电箱 ≥ 50cm | 测量 |

### 4.2 水路验收标准

| 验收项 | 标准 | 检测方法 |
|--------|------|----------|
| 打压测试 | 0.8-1.0MPa 保压 30min，压降 ≤ 0.05MPa | 打压泵加压观察 |
| 接头密封 | 无渗漏 | 目测+纸巾擦拭检查 |
| 管路坡度 | 排水管坡度 2-3% | 水平尺测量 |
| 冷热水间距 | ≥ 15cm | 测量 |
| 热水管保温 | 全程包保温棉 | 目测 |
| 地漏排水 | 无积水，水流顺畅 | 倒水测试 |
| 角阀安装 | 牢固无渗漏 | 手拧检查 |

### 4.3 弱电验收标准

| 验收项 | 标准 | 检测方法 |
|--------|------|----------|
| 网线通断 | 8 芯全通 | 网线测试仪 |
| 网速测试 | 达到标称带宽 | 实际测速 |
| 电视信号 | 信号正常 | 接电视测试 |
| 面板安装 | 平整、牢固 | 目测+手摸 |

### 4.4 验收注意事项

1. **打压测试必须在场**：水路封槽前必须打压，不合格不能封槽
2. **拍照存档**：所有管线走向、点位位置拍照（标注尺寸），后期打孔挂画对照
3. **逐回路测试**：不要只测总开关，每个分路单独测试
4. **夜间复测**：白天看不出的接线错误，晚上开灯更容易发现问题
5. **保留水电图**：验收后将水电走向图保存好（电子版+纸质版）
6. **试用所有点位**：入住前逐个插座插电测试、逐个龙头开水测试
7. **淋浴试水**：卫生间淋浴区开水 10 分钟，检查楼下天花板有无渗水

## 五、常见坑

### 5.1 电路常见坑

| 坑 | 后果 | 正确做法 |
|----|------|----------|
| 横槽超过 50cm | 削弱墙体承重 | 竖槽为主，横槽 ≤ 50cm |
| 强弱电同管 | 信号干扰、网络不稳 | 分管走线，交叉包锡箔 |
| 线径不够 | 大功率电器跳闸/发热 | 空调、厨房用 4mm² |
| 插座不够 | 入住后满地插排 | 120㎡ 至少 50 个，宁多勿少 |
| 冰箱和厨房同回路 | 厨房跳闸冰箱断电 | 冰箱独立回路 |
| 开关没做双控 | 冬天关灯要下床 | 卧室、楼梯必须双控 |
| 网线用 Cat5e | 未来升级受限 | 直接上 Cat6 |
| 线管弯头太多 | 后期换线穿不过去 | 每管弯头 ≤ 2 个 |
| 配电箱不留空位 | 后期加回路无处装 | 箱体选 24 位，预留 4-6 空位 |
| 线头太短 | 接面板费劲、维修困难 | 暗盒 15cm，配电箱 50cm |
| 地线没接 | 电器漏电无保护 | 所有插座必须接地 |
| 用铝线代替铜线 | 电阻大发热、安全隐患 | 必须用铜芯线 |

### 5.2 水路常见坑

| 坑 | 后果 | 正确做法 |
|----|------|----------|
| 水管走地不打压 | 隐藏漏水，泡坏楼下 | 必须打压测试合格 |
| 热水管不保温 | 热量损失、出热水慢 | 热水管全程包保温棉 |
| 冷热水管同槽 | 冷水被加热、热水被冷却 | 间距 ≥ 15cm |
| 不做防水就贴砖 | 漏水到楼下 | 先防水验收再贴砖 |
| 排水管没坡度 | 排水不畅、积水 | 坡度 2-3%（1m 落差 2-3cm） |
| PPR 管热熔过度 | 管口缩径、流量减小 | 加热 5-7 秒，承插后保持 3-5 秒 |
| 地漏位置不对 | 卫生间最低点不在地漏 | 地漏放在淋浴区正下方 |
| 马桶移位太远 | 排水不畅、堵塞 | 移位 ≤ 10cm，超了用移位器 |
| 水管接头藏在墙内 | 接头漏水无法维修 | 接头尽量留在可检修位置 |
| 没装角阀 | 龙头漏水无法关闭 | 每个用水点前装角阀 |

### 5.3 综合常见坑

| 坑 | 后果 | 正确做法 |
|----|------|----------|
| 没拍照存档 | 后期打孔打穿管线 | 每段管线都拍照+标尺寸 |
| 不留检修口 | 吊顶内水管接头无法维修 | 关键接头处开检修口 |
| 水电同槽 | 漏水触电 | 水管电线分槽走 |
| 施工完不验收 | 入住后问题不断 | 必须逐项验收，不合格返工 |
| 改动燃气管 | 安全隐患+违规 | 燃气管只能找燃气公司改 |
