## 一、走顶 vs 走地（布线方式选择）

![走顶vs走地](cabinet-diagrams/07-走顶vs走地.png)

### 1.1 走地（地面布管）

**优点：**
- 成本低，开槽简单
- 不影响层高，无需吊顶
- 适合层高不足（<2.7m）的户型

**缺点：**
- 维修需撬地砖，代价大
- 漏水不易发现
- 地面有管线交叉风险

**适用场景：**
- 层高 < 2.7m 的户型
- 预算有限
- 电路部分（水路不建议走地）

### 1.2 走顶（吊顶内布管）⭐ 推荐

**优点：**
- 维修方便，不用撬砖（开吊顶检修口即可）
- 漏水即时发现（滴到吊顶就知道）
- 地面完整性好，无裂缝风险
- 强弱电分离更方便

**缺点：**
- 需要吊顶配合，成本较高（吊顶约 150 元/㎡）
- 占用层高（吊顶下吊 25-35cm）

**适用场景：**
- 层高 ≥ 2.8m 的户型
- 水路部分（必须走顶！）
- 厨卫区域

### 1.3 120㎡ 自装建议

| 区域 | 建议 | 原因 |
|------|------|------|
| **水路** | 全部走顶 | 漏水风险大，必须方便检修 |
| **电路（厨卫）** | 随水管走顶 | 和水路同区域，一起做吊顶 |
| **电路（其他）** | 走地为主 | 省钱，厨卫以外无需吊顶 |
| **层高 ≥ 2.8m** | 推荐全走顶 | 长远来看维修成本更低 |
| **层高 < 2.7m** | 走地（厨卫走顶） | 保层高 |

## 二、开关控制方式设计

![开关设计](cabinet-diagrams/08-开关设计.png)

### 2.1 单控开关

一个开关控制一盏灯。

**接线方式：** 火线 L → 开关 L 端 → 开关 L1 出线 → 灯 → 零线 N

**适用位置：**
- 厨房灯（一个入口）
- 阳台灯（一个入口）
- 卫生间灯（门外一个开关）
- 储藏间/衣帽间

### 2.2 双控开关 ⭐ 最常用

两个开关控制一盏灯，任意一个都能开关。

**接线方式：**
```
火线 L → 开关1 的 L 端
开关1 的 L1 → 开关2 的 L1（控制线1）
开关1 的 L2 → 开关2 的 L2（控制线2）
开关2 的 L 端 → 灯 → 零线 N
```

**关键点：** 两个开关之间需要两根控制线（L1-L1，L2-L2），共 3 根线。

**适用位置：**
- **卧室：** 门口 + 床头（进门开灯，躺下关灯）
- **楼梯：** 楼上 + 楼下
- **客厅：** 入户 + 沙发旁
- **长走廊：** 两头

**120㎡ 必做双控的位置：**
| 位置 | 开关1 | 开关2 |
|------|-------|-------|
| 主卧 | 门口 | 床头两侧（各一个） |
| 次卧 | 门口 | 床头 |
| 客厅 | 入户门 | 沙发旁 |
| 楼梯（如有） | 楼上口 | 楼下口 |

### 2.3 三控开关

三个开关控制一盏灯。需要两个双控开关 + 一个中途开关（换向开关）。

**中途开关（6触点）原理：**
- 中途开关内部有两组触点
- 拨动时，将 L1-L1' 和 L2-L2' 交叉切换
- 任意位置拨动都能改变通断状态

**接线方式：**
```
火线 → 开关1(L) → 开关1(L1/L2) → 中途开关(L1/L2)
中途开关(L1'/L2') → 开关2(L1/L2) → 开关2(L) → 灯 → 零线
```

**适用位置：**
- 客厅（入户 + 走廊 + 阳台口）
- 长走廊（两头 + 中间）
- 别墅楼梯（多层控制）

### 2.4 智能开关方案（推荐替代三控）

传统三控需要额外布线（中途开关需 5 根线），成本高。建议用智能无线开关替代：

**方案：**
1. 有线智能开关装在主要位置（门口、客厅主控点）
2. 无线智能开关贴在次要位置（床头、走廊中段）
3. 通过 Zigbee/WiFi 协议联动

**优势：**
- 无线开关不用布线，位置随意
- 可手机/语音控制
- 可设置定时、场景联动

**推荐品牌：** 小米/Aqara、绿米、欧瑞博

## 三、配电箱设计

![配电箱设计](cabinet-diagrams/09-配电箱设计.png)

### 3.1 配电箱配置（12-16 回路）

| 序号 | 回路 | 开关类型 | 电流 | 线径 | 说明 |
|------|------|----------|------|------|------|
| — | **总开关** | 2P 空开 | 63A | 10mm² | 不带漏保 |
| ① | 照明 | 1P+N 漏保 | 16A | 1.5/2.5mm² | 全屋照明 |
| ② | 普通插座1 | 1P+N 漏保 | 20A | 2.5mm² | 客厅+卧室 |
| ③ | 普通插座2 | 1P+N 漏保 | 20A | 2.5mm² | 书房+次卧 |
| ④ | 厨房 | 1P+N 漏保 | 25A | 4mm² | 厨房所有插座 |
| ⑤ | 冰箱（独立） | 1P+N 漏保 | 16A | 2.5mm² | 长期不断电 |
| ⑥ | 卫生间 | 1P+N 漏保 | 20A | 4mm² | 含电热水器 |
| ⑦ | 客厅空调 | 1P+N 漏保 | 25A | 4mm² | 柜机/风管机 |
| ⑧ | 主卧空调 | 1P+N 漏保 | 20A | 4mm² | 挂机 |
| ⑨ | 次卧空调 | 1P+N 漏保 | 20A | 4mm² | 挂机 |
| ⑩ | 电热水器 | 1P+N 漏保 | 25A | 4mm² | 如单独走 |
| ⑪ | 阳台 | 1P+N 漏保 | 16A | 2.5mm² | 洗衣机/烘干机 |
| ⑫ | 弱电 | 1P 空开 | 10A | — | 路由/光猫 |
| — | **预留** | — | — | — | 4-6个空位 |

### 3.2 设计要点

1. **总开关不带漏保**：避免一处漏电导致全屋断电（冰箱断电食物变质）
2. **每个分路带漏保**：1P+N 漏电保护器，动作电流 ≤30mA
3. **冰箱独立回路**：出差不断电
4. **厨房/卫生间用 4mm²**：小家电密集，功率大
5. **箱体选 24 位**：留足扩展空间（未来智能家居、充电桩等）
6. **品牌推荐：** 施耐德、ABB、正泰、德力西

## 四、线径选择

### 4.1 速查表

| 线径 | 最大电流 | 最大功率 | 适用 |
|------|----------|----------|------|
| 1.5mm² | 10A | 2200W | 照明回路 |
| **2.5mm²** ⭐ | 16-20A | 3500-4400W | 普通插座、冰箱 |
| **4mm²** ⭐ | 25-32A | 5500-7000W | 空调、厨房、热水器 |
| 6mm² | 40A | 8800W | 即热热水器、中央空调 |
| 10mm² | 60A | 13200W | 入户总线 |

### 4.2 选择原则

1. **照明**：1.5mm²（部分城市要求 2.5mm²，看当地规范）
2. **普通插座**：2.5mm²
3. **空调/厨房/热水器**：4mm²
4. **即热热水器/中央空调**：6mm²
5. **入户总线**：10mm²

### 4.3 电线类型

| 类型 | 说明 | 适用 |
|------|------|------|
| BV（硬线） | 单股铜芯，硬度高 | 固定布线（墙面/地面） |
| BVR（软线） | 多股铜芯，柔软 | 弱电/需要弯曲处 |
| RVV（护套线） | 多芯护套 | 设备连接线 |

**建议：** 固定布线用 BV 硬线（便宜、连接可靠），弱电用 BVR 或 Cat6 网线。

## 五、电线颜色标准

⚠️ **必须遵守，不得混用！**

| 颜色 | 含义 | 说明 |
|------|------|------|
| 🔴 红色 | 火线（L） | 三相：红/黄/绿 = A/B/C 相 |
| 🔵 蓝色 | 零线（N） | — |
| 🟡 黄绿双色 | 地线（PE） | **绝对不能挪用！** |
| 🟢 绿色 | 开关控制线 | 开关 L1/L2 出线到灯具的控制线 |
| ⚪ 白色 | 双控联线 | 双控开关之间互联的 L1-L1、L2-L2 控制线 |

**开关接线颜色约定：**
- 火线进入开关：**红色**（从配电箱到开关 L 端）
- 开关控制线（到灯具）：**绿色**（开关 L1/L2 出线）
- 双控联线（开关之间）：**白色**（两个开关的 L1-L1、L2-L2 互联）
- 实际施工中控制线也可用黄色，但需做好标记，**绝不能和零线（蓝色）混淆**

**禁忌：**
- 禁止用其他颜色代替地线
- 禁止火线零线颜色混用
- 禁止地线当零线用

## 七、穿线方法与规范

### 7.1 穿线步骤

1. **布管**：线管沿槽固定，弯头用弯管器（弯曲半径 ≥ 6 倍管径）
2. **穿引线**：将穿线钢丝从一端穿入管内，从另一端拉出
3. **绑线**：将电线头与钢丝引线绑牢（胶布缠紧，防止脱落）
4. **拉线**：一人推送（入口端），一人牵引（出口端）
5. **留线头**：**插座暗盒**和**开关暗盒**内均预留 15cm 线头（开关盒内同样需要，方便接面板开关模块）

### 7.2 穿线铁律

| 规则 | 标准 | 说明 |
|------|------|------|
| 管内填充率 | ≤ 40% | 线截面不超过管截面的 40% |
| 同管电线数 | ≤ 3 根 | 散热考虑 |
| 弯头数量 | ≤ 2 个 | 太多穿不过去 |
| 直管长度 | ≤ 15m | 超长需设拉线盒 |
| 弯曲半径 | ≥ 6D | D = 管径 |

### 7.3 线管规格

| 管径 | 适用 | 说明 |
|------|------|------|
| 16mm | 照明 | 穿 1-2 根 1.5mm² 线 |
| 20mm | 普通插座 | 穿 3 根 2.5mm² 线 |
| 25mm | 空调/大功率 | 穿 3 根 4mm² 线 |
