## 一、严重BUG修复

### 1. PWM.c - PWM_WSetCompare 函数修复
- **问题**：`TIM2` 变量名被垃圾字符污染，变成 `Tddddddd...zzzzIM2`
- **影响**：编译失败，尾巴舵机完全无法工作
- **修复**：删除垃圾字符，恢复为 `TIM_SetCompare1(TIM2, Compare)`
- **修复前**：`TIM_SetCompare1(TddddddddddddddddddddddddddddddddddddddddddddddddddddddddddddddddzzzzIM2, Compare);`
- **修复后**：`TIM_SetCompare1(TIM2, Compare);`

---

## 二、安全保护增强

### 2. Servo.c - 舵机角度限幅保护
- **问题**：所有 Servo_Angle 函数没有角度范围限制
- **风险**：传入超出 0-180 度的值会导致舵机堵转，电流过大烧毁
- **修复**：增加 `CLAMP_ANGLE` 宏，强制限制在 0-180 度范围内
- **影响函数**：Servo_Angle1、Servo_Angle2、Servo_Angle3、Servo_Angle4、WServo_Angle

```c
// 新增代码
#define ANGLE_MIN  0
#define ANGLE_MAX  180
#define CLAMP_ANGLE(a) ((a) < ANGLE_MIN ? ANGLE_MIN : ((a) > ANGLE_MAX ? ANGLE_MAX : (a)))

// 每个函数开头增加
Angle = CLAMP_ANGLE(Angle);
```
