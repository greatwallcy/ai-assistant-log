# 机器狗舵机频繁烧毁问题分析与方案

## 背景

机器狗通过语音控制执行动作，单片机根据指令驱动舵机控制腿部运动。供电方案为一节锂电池（2000mAh 三元电池）通过升压模块输出 5V 给舵机供电，舵机为常供电模式。

**问题**：舵机频繁烧毁。

---

## 一、原因分析

### 1. 电源问题（核心原因）

#### 1.1 电感电流余量不足
- L1 标称 1.5uH/4.5A，MP3421 boost 最大输出 2.1A，MP3423 最大输出 3.1A
- 4个 SG90 舵机同时负载时，峰值电流可达 3-5A（单舵机堵转约 500-700mA）
- 超过电感/芯片额定电流时，boost 输出电压塌陷或产生高压尖峰，直接烧舵机

#### 1.2 输出电容耐压余量太小
- EC1 = 470uF/6.3V，工作在 5V 输出上，裕量仅 26%
- 舵机堵转/启停瞬间产生反冲电压，6.3V 耐压极易被击穿
- 电解电容击穿后纹波增大 → 供电不稳 → 烧舵机

#### 1.3 瞬态响应不足
| 场景 | 电流需求 | 说明 |
|------|----------|------|
| 空载/轻载 | ~200-400mA | 4个舵机静态 |
| 正常动作 | 1-2A | 逐个/分时动作 |
| 堵转保持 | 2-3A | 4个同时堵住 |
| 突然换向 | **4-5A 瞬时尖峰** | 杀手级场景 |

Boost 环路响应跟不上瞬态尖峰 → 输出电压过冲 → 烧舵机。换更大电流的 boost 只解决一部分，根本思路需要改。

### 2. 舵机常供电 + 堵转发热
- 机器狗站立时，舵机持续输出力矩对抗重力，内部电机持续堵转
- 电流全部转化为热量，普通 SG90 堵转温度可达 60-80°C
- 长时间运行必然烧毁

### 3. PWM 信号可能超范围
- STM32F103C8T6（8MHz 晶振），定时器输出 PWM
- 如果脉宽超出 0.5ms-2.5ms 范围，舵机控制板会异常工作
- 脉宽 >2.5ms 时，舵机被驱动到极限位置并持续过流

### 4. 缺少保护电路
- 原理图中 5V0 到舵机接口无保险丝、TVS 或稳压管
- D1、D3 标注 NC（未贴装），无保护二极管
- 舵机堵转反冲、接插件接触不良产生的电弧可能损坏舵机

## 二、电源方案改进

### 核心思路：两条电源路径

| 路径 | 芯片 | 用途 | 特点 |
|------|------|------|------|
| 5V_SYS | MP3421（保留） | 语音模块、MP3播放器 | 轻载，<500mA，一直开 |
| 5V_SERVO | 独立 Boost | 4个舵机 | 大电流，可控开关 |

### 架构

```
2000mAh 锂电池
    │
    ├──[MP3421]──5V_SYS──→ 语音模块/MP3播放器/OLED（恒供）
    │                    └──→ [1117-3.3V]──3.3V──→ STM32
    │
    ├──[STM32 GPIO_EN]──→ [P-MOSFET开关]
    │                         │
    │                    [TPS61088/4A]──5V_SERVO
    │                         │
    │                    [1000uF/10V电容]
    │                         │
    └──────────────────── 4x MG90S（金属齿轮舵机）
```

### 舵机电源开关方案（P-MOSFET）

```
VBAT ──→ [Boost芯片 5V输出] ──→ S
                               MOSFET (P-ch)
                               D ──→ 5V_SERVO → 舵机
                               G ←── STM32 GPIO (通过N-MOS或三极管反相)

推荐MOSFET: AO3401 / SI2301 / AOD4184A
- Vds: -30V, Id: -4-5A, Rds(on): <50mΩ
- 成本 < 0.3元
```

或使用负载开关 IC：

| 芯片 | 最大电流 | 特点 | 成本 |
|------|----------|------|------|
| RT9742 | 2A | 内置软启动、过流保护 | ~0.5元 |
| SY6280 | 2.5A | 软启动、限流可调 | ~0.4元 |
| XC6194 | 3A | 使能控制、过流保护 | ~0.6元 |

### 舵机 Boost 选型

| 芯片 | 输入 | 输出 | 最大电流 | 关键优势 | 参考价 |
|------|------|------|----------|----------|--------|
| MT3608 | 2-24V | 5V | 2A | 极便宜，外围简单 | ~0.2元 |
| **TPS61088** | 2.7-12V | 5V | **4A** | 瞬态响应好，软启动 | ~2元 |
| MT3581 | 2-6V | 5V | **4A** | 专为锂电池设计 | ~1.5元 |
| FP6276 | 2.4-4.5V | 5V | **3A** | 内置MOSFET，SOT23-6 | ~0.8元 |
| IP5328P | 锂电池 | 5V | **3A** | 集成充电+放电+Boost | ~2元 |

**推荐：TPS61088 或 MT3581**，4A 能力 + 好的瞬态响应，配合输出端 1000uF/10V 电解电容吸收尖峰。

## 三、SG90 替代方案（同尺寸升级）

SG90 尺寸约 23×12.2×29mm，同尺寸性能更好的选择：

| 舵机 | 尺寸 | 扭矩 | 速度 | 齿轮 | 关键升级 | 参考价 |
|------|------|------|------|------|----------|--------|
| SG90（原） | 23×12×29mm | 1.8kg·cm | 0.12s/60° | 塑料 | — | ~3元 |
| DS041MG | 23×12×29mm | 2.2kg·cm | 0.10s/60° | 金属 | 金属齿轮，寿命10x | ~8元 |
| GDW DS04 | 23×12×29mm | 2.5kg·cm | 0.09s/60° | 金属 | 数字控制，精度高 | ~10元 |
| ES08MA II | 23×12×29mm | 2.6kg·cm | 0.10s/60° | 金属 | 金属外壳散热好 | ~12元 |
| TowerPro MG90S | 23×12×29mm | 2.2kg·cm | 0.11s/60° | 金属 | 经典升级方案 | ~6元 |
| SG92R | 23×12×29mm | 2.5kg·cm | 0.09s/60° | 金属 | 双滚珠轴承 | ~8元 |

**推荐 MG90S 或 DS041MG**：
1. 金属齿轮 — SG90 塑料齿轮在机器狗上容易打齿磨损
2. 堵转电流更低（~400mA vs SG90 的 650mA）— 对电源更友好
3. 散热更好 — 长时间堵转不容易烧
4. 同尺寸直接替换 — PCB 不用改

## 四、改进建议（优先级排序）

| 优先级 | 改进项 | 说明 |
|--------|--------|------|
| P0 | EC1 换 470uF/10V+ | 耐压余量是最低成本的修复 |
| P0 | 5V 输出端加 TVS（如 SMBJ5.0A） | 吸收瞬态过压 |
| P1 | 检查 PWM 脉宽范围 | 确保软件 0.5-2.5ms |
| P1 | 舵机接口加 0.5-1A 自恢复保险丝 | 防止堵转烧机 |
| P2 | 舵机电源独立 + MOSFET 开关 | 按需供电，减少发热 |
| P2 | 换用 TPS61088 等大电流 Boost | 独立供电路径 |
| P2 | SG90 替换为 MG90S/DS041MG | 金属齿轮，低堵转电流 |

## 五、软件改动要点

舵机动作前先打开 MOSFET，延时 50ms 等 Boost 稳定，再发 PWM；动作完成后断电：

```c
// 舵机电源控制引脚
#define SERVO_PWR_EN  GPIO_PIN_x

void servo_power_on(void) {
    HAL_GPIO_WritePin(GPIOx, SERVO_PWR_EN, GPIO_PIN_SET);
    HAL_Delay(50);  // 等待 Boost 稳定
}

void servo_power_off(void) {
    HAL_GPIO_WritePin(GPIOx, SERVO_PWR_EN, GPIO_PIN_RESET);
}

// PWM 限幅保护
uint16_t clamp_pulse(uint16_t pulse_us) {
    if (pulse_us < 500) return 500;
    if (pulse_us > 2500) return 2500;
    return pulse_us;
}
```
