```

  ├── P-01~04 电源测试
  │     └── V-01~06 INA226电压采集
  │     └── T-01~04 TMP112温度采集

  ├── B-01~12 主动均衡（依赖GPIO+电源+INA226）
  ├── C-01~05 CAN通讯
  ├── E-01~04 EEPROM
  ├── F-01~03 风扇控制
  └── R-01~05 保护功能（最后执行）
```
