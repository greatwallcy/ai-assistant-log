## 二、DNB1101B 菊花链架构

### 2.1 芯片特性

- **单串管理**：1 颗 DNB1101B 管理 1 节电芯
- **电压精度**：±2mV（14-bit ADC）
- **温度精度**：±2.5K（片上传感器，无需外接 NTC）
- **EIS 阻抗测量**：0.0075Hz ~ 7800Hz（可用于内阻/SOH 评估）
- **菊花链最大数量**：252 颗
- **通讯速率**：1 Mbps（差分 DIO）
- **100 串数据读取**：3.5ms
- **封装**：HTSSOP20 (6.5mm × 4.4mm)

### 2.2 双菊花链拓扑

系统采用**两条独立菊花链**，每链连接 2 块采集板（26 颗 DNB1101B）：

```
菊花链 1 (SPI1)：
MCU SPI1 (PB5/MOSI, PB4/MISO, PB3/SCK, PB12/SPI1_EN)
  ↓
采集板 A: DNB1101B #1~#13 (SPI Mode #1 + Measurement Mode #2~#13)
  ↓ DIO 差分
采集板 B: DNB1101B #14~#26

菊花链 2 (SPI2)：
MCU SPI2 (PB15/MOSI, PB14/MISO, PB13/SCK, PD8/SPI2_EN1)
  ↓
采集板 C: DNB1101B #27~#39 (SPI Mode #27 + Measurement Mode #28~#39)
  ↓ DIO 差分
采集板 D: DNB1101B #40~#52
```

## 五、均衡拓扑详细说明

### 5.1 充电均衡工作流程

```
24V 系统供电 (TPS54360 输出)
    ↓
VPS2606 Buck 降压 → 4V（每块采集板 1 颗，由 ENa/ENb/ENc/ENd 控制）
    ↓
通过连接器送到采集板（均衡母线）
    ↓
74HC154 译码器（MCU 设置 CTR_x1~CTR_x4 选择 13 串中的目标串）
    ↓
MOSFET 开关导通（DNB1101B VSW 或外部 MOSFET）
    ↓
4V → 限流电阻 → 电芯充电 → GND
    ↓
INA226 监控均衡电流（I2C 回报 MCU）
    ↓
DNB1101B 监测电芯电压（通过菊花链回报 MCU）
    ↓
电压达标 → MCU 关闭 VPS2606 + 74HC154
```

### 5.2 控制信号流

1. **板选**：MCU 设置 ENa/ENb/ENc/ENd → 使能对应 VPS2606
2. **方向**：MCU 设置 CDa/CDb/CDc/CDd → 控制均衡方向
3. **串选**：MCU 设置 CTR_x1~CTR_x4 → 74HC154 选通目标串
4. **电流监控**：INA226 通过 I2C 回报电流值
5. **电压监控**：DNB1101B 通过菊花链回报电压值

## 六、设计问题与建议

### ✅ 已确认正确

1. CAN 芯片：CA-IS3062VW
2. EEPROM：AT24C16M/TR (2KB)
3. 系统电源：TPS54360BDDARQ1
4. 电芯监控：DNB1101B（一芯一管菊花链）
5. 双菊花链架构：SPI1（板 A+B，26 串）+ SPI2（板 C+D，26 串）
6. GPIO 分配完整，无引脚冲突
7. PD8 在 LQFP100 上确实可用（Pin 55）
8. PB1 仅用于 CTR_d4，SPI1_EN 使用 PB12（Pin 51）

### ⚠️ 建议关注

1. **DNB1101B SPI_EN 硬件配置**
   - 菊花链中每段链头 1 颗需配置为 SPI Mode（SPI_EN=VCC）
   - 其余配置为 Measurement Mode（SPI_EN=GND）
   - 建议确认采集板上的硬件跳线/电阻配置方式

2. **均衡电流来源明确**
   - VPS2606 输出 4V 通过外部路径均衡
   - DNB1101B 也支持内部电流源均衡（205mA）
   - 建议明确主要使用哪种方式

3. **74HC154 使能引脚接法**
   - 4 块采集板的 74HC154 地址线由 MCU GPIO 直接控制
   - 需确认 G1/G2 使能引脚在采集板上的接法

4. **SPI1 引脚 Remap**
   - PB3/PB4/PB5 默认为 JTAG 功能（JTDO/NJTRST）
   - 用作 SPI1 需要 GPIO Remap（AFIO_MAPR 寄存器）
   - 程序中必须执行 `GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE)`

5. **菊花链 DNB1101B 代码实现**
   - task_spi_daisy.c 需要实现完整的 DNB1101B 通讯协议
   - 包括：枚举（Enumerate）、初始化（Initialise）、数据读取（GetData）、均衡控制（SetBalCurr）

## 八、VPS2606 主动均衡模块详解

### 8.1 模块架构（VP2606-014 方案）

VPS2606 主动均衡模块为**隔离双向均衡方案**，集成以下核心器件：

| 器件 | 功能 |
|------|------|
| VPS2606 | 原边控制器（SOP-8），正向充电 PWM 控制 |
| VPS2633 | 副边控制器（QFN5x5），反向放电 + 同步整流 |
| 变压器 VPE66BMS48C | 6KV 隔离，能量传递 |
| SGM6623 | 辅助电源 |

### 8.2 关键规格

| 参数 | 规格 |
|------|------|
| 输入电压 | 16~32V（电池组电压） |
| 输出电压 | 1.5~4V（可调，单电阻设定） |
| 输出电流 | **2A 恒流** |
| 隔离电压 | **6000VDC（加强绝缘）** |
| 效率 | 83%（正向），80%（反向） |
| 开关频率 | 200kHz |
| 待机功耗 | <5uA（EN=0 时） |
| 工作温度 | -40°C ~ +85°C |
| 封装尺寸 | 50mm × 25mm × <10mm |

### 8.3 引脚定义

| 引脚 | 名称 | 功能 |
|------|------|------|
| 1-3 | VIN+ | 输入正（接电池组正极） |
| 4-6 | VIN- | 输入负（EN/CD 参考地） |
| 7 | EN | 使能引脚（MCU GPIO 控制） |
| 8 | CD | 方向控制引脚（MCU GPIO 控制） |
| 9-13 | VO- | 隔离输出负 |
| 14-18 | VO+ | 隔离输出正 |

### 8.4 控制逻辑

| EN | CD | 状态 | 说明 |
|----|-----|------|------|
| 0 | 0 | **关闭** | 待机 <5uA，不消耗电池 |
| 1 | 0 | **正向充电** | VIN (24V) → 变压器 → VO (4V/2A) |
| 1 | 1 | **反向放电** | VO (电芯) → 变压器 → VIN (电池组) |

**控制电平**：<1V = 低电平(0)，2.8~3.8V = 高电平(1)
