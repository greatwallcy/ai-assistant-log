## 一、系统架构总览

整个BMS系统由**主板（MCU板）** + **采集板（Collection Board / VTR板）** 两块板组成：

```
┌─────────────────────────────────────────────────────┐
│                    主板 (Onedie_MCU)                  │
│                                                       │
│  STM32F103VET6 ←→ 4×均衡模块(VPS2606+74HC154)        │
│       ↕                    ↕                          │
│  CA-IS3062VW(CAN)    INA226×4 + TMP112×4              │
│  AT24C16M(TR)        SGM6603(均衡母线)                │
│  TPS54360(电源)       SPI1/SPI2 → 菊花链              │
│                                          ↓            │
└──────────────────────────────────────────────────────┘
                                           ↓
┌──────────────────────────────────────────────────────┐
│            采集板 (Collection Board / VTR)             │
│                                                       │
│  74HC154×2 + ULN2803×2 + MOSFET 矩阵开关(32路)       │
│  PC817/6N137 光耦隔离                                  │
│  DNB1101 × 13 双向菊花链（MOSFET H桥主动均衡）        │
│  LM2596(5V) + AMS1117-3.3(3.3V) 电源                  │
│  74HC154 + 74HC04 + PJM10N10PSA 扩展驱动              │
└──────────────────────────────────────────────────────┘
```

## 四、采集板电路拓扑详解

### 4.1 矩阵开关拓扑（第1页）

```
MCU BATSEL_0~3 → PC817光耦隔离 → 74HC154译码(4→16) → ULN2803驱动 → AO3400/SI2301 MOSFET开关
                                                                 ↓
                                                          DNB1101采样通道选择
```

- **2片74HC154**：提供32路独立开关通道
- **2片ULN2803**：达林顿驱动，每片8路，共16路×2=32路
- **光耦隔离**：PC817隔离控制信号，保护MCU免受高压干扰

### 4.2 DNB1101菊花链拓扑（第1-2页）

- **13个DNB1101**串联，双向菊花链通信
- 每个DNB1101支持多路电芯电压采样
- 菊花链两端需终端电阻匹配（120Ω）
- 通过SPI/SDO/SDI级联数据传输

### 4.3 主动均衡拓扑（第2页）

```
相邻电芯 B(n) ←→ L1020AD H桥 ←→ B(n+1)
                    ↑
              GA/GB控制信号（来自DNB1101或MCU）
```

- **H桥结构**：每对相邻电芯间4个L1020AD MOSFET组成H桥
- **双向能量转移**：高压电芯→低压电芯，提高均衡效率
- **保护**：ESD103AWS（栅极保护）+ SD103AW（过压钳位）+ 51Ω限流

### 4.4 扩展驱动拓扑（第3页）

- **额外74HC154**：扩展更多控制通道
- **74HC04反相器**：信号反相，适配不同极性需求
- **PJM10N10PSA NMOS**：大电流驱动（10A/100V），驱动均衡负载
- **设计问题标注**："GPIO口不够，驱动控制需要16个GPIO。4/16线译码器只有16种状态，不满足需求"

### 4.5 电源链路

```
电池组电压 → LM2596(DC-DC降压) → 5V → AMS1117-3.3(LDO) → 3.3V
                                         ↓                    ↓
                                    74HC154/ULN2803        DNB1101/光耦
```

## 六、设计问题与风险点

### 🔴 严重问题（P0必须修改）

#### 1. GPIO数量不足（采集板第3页已标注）
- **问题**：原理图自注"GPIO口不够，驱动控制需要16个GPIO。4/16线译码器只有16种状态，不满足需求"
- **分析**：13个DNB1101 + 32路矩阵开关 + 均衡控制，需要的GPIO远超STM32F103VET6可用数量
- **建议**：
  - 增加I/O扩展芯片（如PCA9555 I2C扩展16路GPIO）
  - 或改用引脚更多的MCU（如STM32F103ZET6，144脚）

#### 2. 菊花链DNB1101通信未实现
- **问题**：task_spi_daisy.c 全是TODO
- **影响**：13片DNB1101无法通信，采集板完全无法工作
- **建议**：最高优先级实现

#### 3. 主板均衡拓扑与采集板不一致
- **主板**：VPS2606 + 74HC154 简单开关均衡
- **采集板**：L1020AD MOSFET H桥主动均衡
- **问题**：两块板的均衡控制逻辑不同，需确认哪块板负责均衡
- **建议**：明确均衡功能分配——主板的VPS2606模块还是采集板的H桥？

#### 4. CA-IS3062VW隔离供电验证
- 需对照数据手册确认VCC1/VCC2供电和去耦设计

### 🟡 需要关注（P1）

#### 5. 菊花链可靠性（13节点串联）
- 任一DNB1101故障→后续全部失联
- **建议**：软件心跳检测 + 硬件旁路电路

#### 6. MOSFET H桥均衡电流路径
- L1020AD Rds(on) + PCB走线电阻 + 采样电阻串联
- 需计算总阻抗确认均衡电流是否满足设计目标
- **建议**：选择低Rds(on) MOSFET，加宽铜箔

#### 7. 光耦时序
- PC817典型延迟5μs，6N137约1μs
- 确认选用哪种光耦，以及译码器切换速率是否匹配

#### 8. 电源链路效率
- 电池→LM2596→5V→AMS1117→3.3V，两级降压效率较低
- **建议**：如果电池电压较高（>12V），LM2596发热会较大

#### 9. 74HC04反相器用途
- 第3页增加74HC04反相器，需确认其具体连接和用途
- 可能用于适配不同极性的控制信号

#### 10. FreeRTOS任务优先级
- 建议：菊花链采样 > 均衡控制 > CAN通信 > EEPROM存储

### 🟢 设计合理之处

#### 11. 模块化架构 ✅
- 主板+采集板分离，扩展灵活

#### 12. 引脚分配 ✅
- 主板59引脚使用合理，无冲突

#### 13. 隔离设计 ✅
- CAN隔离（CA-IS3062VW）+ 控制信号光耦隔离（PC817）

#### 14. 保护电路 ✅
- ESD保护（ESD103AWS）、肖特基钳位（SD103AWS）、TVS保护

#### 15. 主动均衡拓扑 ✅
- H桥双向能量转移，效率优于被动均衡

## 十、总结

**硬件设计**：系统采用主板+采集板分离的模块化架构。主板基于STM32F103VET6，集成TPS54360电源、CA-IS3062VW隔离CAN、AT24C16 EEPROM、4路VPS2606均衡模块。采集板采用13片DNB1101菊花链+MOSFET H桥主动均衡+74HC154/ULN2803矩阵开关方案。

**主要发现**：
1. 采集板原理图自标注"GPIO口不够"——这是硬件设计的已知问题，需增加I/O扩展
2. 主板均衡方案（VPS2606简单开关）与采集板均衡方案（L1020AD H桥）不一致，需明确功能分配
3. 菊花链DNB1101通信协议未实现，是软件最大缺口

**最紧迫行动**：
1. 解决GPIO不足问题（I/O扩展或换MCU）
2. 实现DNB1101菊花链SPI协议
3. 明确两块板的均衡功能分工
4. 验证CA-IS3062VW隔离供电设计
