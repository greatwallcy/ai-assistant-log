## 二、主控板 (MCU) 详细分析

### 2.1 电源架构

**四级电源转换**：

```
电池组电压 (52S)
    ↓
SGM6603 升压 × 4（每块采集板 1 路）→ V_EQU（均衡母线电压 ~12V）
    ↓
24V 系统供电
    ↓
VPS2606 降压 × 4（每块采集板 1 路）→ 4V（均衡充电电压）
    ↓
MP2315 降压 → +3.3V（MCU、CAN、EEPROM 数字电源）
    ↓
SGM2036 LDO → +1.8V / +2.5V（采集板模拟电源）
```

**关键芯片**：
- **SGM6603** × 4：Boost 升压，产生 V_EQU 均衡母线，EN 信号经 CA-IS3720HG 隔离
- **VPS2606** × 4：Buck 降压 24V → 4V，为均衡充电供电，EN 信号经 CA-IS3720HG 隔离
- **MP2315**：Buck 降压，3.3V 数字电源
- **SGM2036** × 4：LDO，为采集板提供 1.8V/2.5V 模拟电源
- **隔离电源模块** × 4：为采集板侧 CA-IS3720HG 高压侧供电

### 2.2 数字隔离 — 8 颗 CA-IS3720HG（16 通道）

| 芯片 | 通道 | MCU 侧信号 | 隔离侧信号 | 功能 |
|------|------|-----------|-----------|------|
| U2 | CH1 | MCU GPIO | ENA | SGM6603#1 Boost 使能 |
| U2 | CH2 | MCU GPIO | ENB | SGM6603#2 Boost 使能 |
| U3 | CH1 | MCU GPIO | ENC | SGM6603#3 Boost 使能 |
| U3 | CH2 | MCU GPIO | END | SGM6603#4 Boost 使能 |
| U4 | CH1 | MCU GPIO | AUX_P | H 桥方向控制 P |
| U4 | CH2 | MCU GPIO | AUX_N | H 桥方向控制 N |
| U9 | CH1 | MCU GPIO | ENa | VPS2606#1 使能（采集板 A） |
| U9 | CH2 | MCU GPIO | ENb | VPS2606#2 使能（采集板 B） |
| U10 | CH1 | MCU GPIO | ENc | VPS2606#3 使能（采集板 C） |
| U10 | CH2 | MCU GPIO | ENd | VPS2606#4 使能（采集板 D） |
| U11 | CH1 | MCU GPIO | 待确认 | 预留/扩展 |
| U11 | CH2 | MCU GPIO | 待确认 | 预留/扩展 |
| U12 | CH1 | MCU GPIO | 待确认 | 预留/扩展 |
| U12 | CH2 | MCU GPIO | 待确认 | 预留/扩展 |
| U13 | CH1 | MCU GPIO | 待确认 | 预留/扩展 |
| U13 | CH2 | MCU GPIO | 待确认 | 预留/扩展 |

### 2.3 74HC154 译码器接口

**重要澄清**：74HC154（4-16 译码器）位于**采集板上**，不在主控板。

- 主控 MCU 输出 **4 位地址线 A0-A3**，通过连接器并联到 4 块采集板
- 每块采集板上的 74HC154 接收相同的 A0-A3
- **板选机制**：VPS2606 的 ENa/ENb/ENc/ENd 决定哪块采集板的均衡电路工作
- **串选机制**：A0-A3 决定该板上 13 串中的哪一串被选中（Y0-Y12）

### 2.4 I2C 总线（INA226 电流传感器）

4 路独立 I2C 总线（226_SCLa/SDAa ~ 226_SCLd/SDAd），每路连接一块采集板上的 INA226。

### 2.5 其他外设

- **CAN**: TJA1050 收发器，500Kbps，连接整车 CAN 总线
- **EEPROM**: AT24C16（2KB），I2C 接口，存储配置参数
- **SPI**: 连接采集板 MCU，通讯协议
- **SWD**: 调试接口（PA13/PA14）

## 三、采集板 (VTR) 详细分析

### 3.1 核心器件

| 器件 | 型号 | 功能 |
|------|------|------|
| AFE | BQ76940 (TI) | 13 串电压 + 温度采集，SPI 通讯 |
| 局部 MCU | STM32F103C8T6 | 管理 BQ76940、CAN 上报、均衡控制 |
| 译码器 | 74HC154 | 4-16 线译码，选通 13 路均衡开关 |
| 电流传感器 | INA226 | I2C 接口，监控均衡电流 |
| MOSFET 阵列 | 13 组 H 桥 | 每串电池一组，控制均衡电流方向 |
| 限流电阻 | 47Ω/0.125W × 13 | R16-R28，均衡限流 |
| 时钟 | 16MHz 晶振 + 32.768kHz | STM32 时钟源 |
| CAN | 收发器（见页 3） | 与主控板 CAN 通讯 |

### 3.2 电压采集拓扑

```
电池单体正极 → 限流电阻 47Ω → BQ76940 VC 引脚
电池单体负极 → BQ76940 VC 引脚（下一通道）
```

- BQ76940 的 VC1-VC13 直接连接 13 串电池
- 47Ω 电阻同时作为均衡限流和采样隔离

### 3.3 主动均衡拓扑（充电均衡）

**工作原理**：

```
主控板 VPS2606: 24V → 4V
    ↓（通过连接器 4V 引脚）
采集板均衡母线
    ↓
74HC154 译码选通
    ↓
MOSFET H 桥导通（高侧 + 低侧）
    ↓
均衡电流路径: 4V → MOSFET(高侧) → 47Ω 限流 → 电芯 → MOSFET(低侧) → GND
    ↓
INA226 实时监控电流 → I2C 回报主控
    ↓
BQ76940 监测电芯电压 → 达标后关闭均衡
```

**控制流程**：
1. 主控 MCU 使能 VPS2606（ENa/ENb/ENc/ENd 之一）→ 选中一块采集板
2. VPS2606 输出 4V 均衡电压
3. 主控 MCU 设置 A0-A3 地址 → 74HC154 选通对应电芯的 MOSFET
4. 主控 MCU 控制 AUX_P/AUX_N → 确定 H 桥导通方向
5. 均衡电流流经选中电芯，INA226 闭环监控
6. BQ76940 检测电压达标 → 主控关闭均衡

### 3.4 电源轨

采集板从主控板获取：
- **+3.3V**：数字电源（MCU、CAN）
- **+2.5V**：BQ76940 模拟电源（DECAP 引脚）
- **+1.8V**：BQ76940 数字电源（VC 引脚参考）
- **4V**：均衡充电电源（VPS2606 输出）
- **GND**：数字地 + 模拟地分离

## 四、设计问题与风险点（修正后）

### ⚠️ 需关注

#### 1. CAN 收发器型号不一致
- **原理图**: TJA1050（NXP）
- **程序注释**: CA-IS3062VW（隔离 CAN）
- **影响**: 引脚定义、电气参数不同，需确认实际 PCB 上焊接的型号
- **建议**: 统一 BOM，程序注释与原理图保持一致

#### 2. EEPROM 容量确认
- **原理图**: AT24C16（2KB，地址 A0-A2）
- **程序注释**: AT24C02（256B）
- **影响**: 如果程序按 256B 编址，多余空间无法使用；如果按 2KB 编址但实际焊 256B，会地址回绕
- **建议**: 确认 BOM 实际型号，程序 I2C 地址与之匹配

#### 3. 菊花链 DNB1101B 未实现
- task_spi_daisy.c 全部为 TODO
- 如果设计意图是用 DNB1101B 菊花链采集而非 BQ76940，需尽快实现
- 如果已决定用 BQ76940 方案，建议删除菊花链相关代码避免混淆

#### 4. 均衡电流开环风险
- INA226 可以采集均衡电流，但程序中缺少闭环控制逻辑
- **风险**: VPS2606 输出电压随温度/负载变化，均衡电流不恒定
- **建议**: 增加 PID 或简单阈值控制，基于 INA226 反馈调节均衡占空比

#### 5. 采集板 STM32 与 BQ76940 SPI 引脚映射
- 需确认程序中 SPI 引脚定义（SCK/MOSI/MISO/CS）与 VTR 原理图实际 PCB 走线一致
- 特别注意 STM32F103C8T6 的 SPI1（PA5-PA7）vs SPI2（PB13-PB15）

#### 6. 采集板侧 I2C 地址冲突风险
- 每块采集板有 BQ76940（I2C/SPI）+ INA226（I2C）
- 如果 INA226 的 A0/A1 地址引脚未区分，4 块板共享 I2C 总线时会地址冲突
- 当前设计是 4 路独立 I2C 总线（每板一路），OK

## 七、结论

1. **主控板与采集板拓扑一致**：VPS2606（24V→4V）+ 74HC154（选串）+ MOSFET H 桥（控流）构成完整的主动均衡系统
2. **系统配置合理**：1 主控 + 4 采集 = 52 串，模块化设计便于维护和扩展
3. **GPIO 数量足够**：8 颗 CA-IS3720HG（16 通道）+ 直连 GPIO 覆盖所有控制信号
4. **需修正的问题**：CAN 型号、EEPROM 容量、菊花链代码、均衡闭环控制
