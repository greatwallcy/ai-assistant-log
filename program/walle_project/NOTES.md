# ⚠️ 注意事项

## 必读事项

### 1. PCB 版本选择
**一定选四层板改进版！** 旧版六层板有以下问题：
- LCD 屏幕接口电路异常，图像显示不正常
- VC-02 串口接线有问题
- 眼灯接口位置不合理

### 2. VC-02 咪头故障排查
作者遇到的问题：咪头不工作，MIC+ 和 MIC- 短路。

排查过程：
1. 最初怀疑芯片底部连锡 → 拆解困难
2. 最终发现是**屏蔽壳有问题**
3. 拆掉屏蔽壳后故障排除

**结论**：如果咪头不工作，先检查/更换屏蔽壳，不要急着拆芯片。

### 3. VC-02 UART 飞线
原理图中未设计 UART 复用引脚，实际需要：
- GPIO_B2 飞线 → UART1_TX
- GPIO_B3 飞线 → UART1_RX
- 连接到 GD32 的 USART2

焊接时预留飞线位置。

### 4. 电机驱动滤波
VP 引脚需要 250μF + 100nF 滤波电容：
- ❌ 大电解电容占面积
- ✅ 4 个 10μF 贴片电容并联 = 40μF（作者实测可行）
- 搭配 100nF 小电容

### 5. 眼灯驱动
- 1W LED 额定电流：350mA
- MCU IO 口最大输出：70mA
- **必须使用 NPN 三极管**（最大输出 500mA）驱动
- 绝对不能直接连接 MCU IO 口

### 6. LED 限流电阻计算
公式：限流电阻 = (供电电压 - LED压降) / 额定电流

24V 系统的电阻值比 3.3V/5V 系统小得多，不要凭经验估算！
推荐使用在线计算器：搜索「LED 限流电阻阻值计算器」

## 3D 打印注意事项

### 支撑清理
- 履带部分支撑极其难清理
- **必须用镊子一点一点清理**
- 作者花了一整天清理所有支撑
- 清理不干净 → 零件装不上 / 履带卡顿

### 打印密度
- 结构件（骨架、关节）：填充 40% 以上
- 外壳装饰件：可适当降低到 20-30%
- 履带：建议 50%+（承重+耐磨）

### 打印方向
- 注意零件的打印方向，减少支撑需求
- 关节件注意配合面朝上

## 软件调试注意事项

### VC-02 数据格式
- SDK 生成的程序只能发送十六进制数
- 串口接收缓存是 uint8_t 型
- 需要 HexChar 函数做 ASCII → Hex 转换

### 调试顺序建议
1. 电源 → 确认各电压正常
2. 蜂鸣器 → 最简单的输出测试
3. 眼灯 → GPIO 输出测试
4. LCD → 显示功能验证
5. 电机驱动 → 履带行走
6. 舵机 → PCA9685 I²C 通讯
7. VC-02 语音 → 串口通讯
8. 蓝牙 HC-05 → 无线遥控
9. 摄像头 → 图传功能
10. 综合运行 → 全功能联调
