# 🔧 准备步骤

## 第一阶段：资料获取与采购（1-2 周）

### 1. 获取开源资料
- 从 [oshwhub 开源页面](https://oshwhub.com/gshaoburuchuan/li-chuang-kai-fa-ban-liang-shan-pai-wa-li-ji-qi-ren) 下载：
  - 原理图
  - PCB 文件
  - 程序源码
  - 3D 模型文件（STL/STEP）
- ⚠️ **务必选择「改进版四层板」**，不要用旧版六层板

### 2. PCB 打样
- 嘉创下单四层板
- 工艺：沉金
- 颜色：绿色（目前只有绿色可选）
- 面积与梁山派开发板一致

### 3. 元器件采购
- 立创商城一站式配单
- 对照 [BOM 清单](BOM.md) 逐项确认
- 重点确认：
  - VC-02 买 CN 版本
  - 24V 电机扭矩足够
  - PCA9685、AS4950 等 IC 型号无误

### 4. 3D 打印下单
- 几百个零件，打印周期较长
- 填充密度建议：结构件 40%+，装饰件可适当降低
- 支撑设置要合理，特别是履带部分

---

## 第二阶段：焊接组装（3-5 天）

### 焊接顺序（非常重要！）

```
电源模块 → 测试降压正常
    ↓
驱动模块（电机驱动、舵机驱动）→ 逐个验证
    ↓
外设模块（LCD、摄像头、语音、蓝牙）→ 功能测试
```

**每一步焊完都要测试，通了再焊下一步！**

### 关键焊接点

1. **电源降压（TPS54331）**
   - 确认输出电压正确后再接后续电路
   - LED 限流电阻：24V 用 ~2.3kΩ（按公式计算）

2. **电机驱动（AS4950）**
   - VP 引脚滤波：4 个 10μF 贴片并联 + 1 个 100nF
   - 作者实测此方案可行

3. **眼灯驱动**
   - 1W LED 需 350mA，MCU IO 仅 70mA
   - **必须通过 NPN 三极管驱动**，不能直连

4. **VC-02 语音模块**
   - 需要配置 SDK：GPIO_B2 → UART1_TX，GPIO_B3 → UART1_RX
   - 与 GD32 的 USART2 通讯
   - ⚠️ 原理图中可能缺少 UART 复用引脚设计，可能需要飞线

---

## 第三阶段：3D 打印件清理与组装（2-3 天）

1. **清理支撑**
   - 履带支撑用镊子一点一点清理
   - 作者花了一整天才清理完所有支撑
   - 清理不干净会影响后续安装

2. **组装顺序**
   - 先装内部骨架/机械结构
   - 安装电机和履带
   - 安装 PCB 和电池
   - 最后装外壳

3. **布线**
   - 注意舵机线、电源线的走线
   - 避免干涉运动部件

---

## 第四阶段：软件调试（3-5 天）

### 程序模块

| 模块 | 说明 |
|------|------|
| 语音交互 | VC-02 → UART → GD32，语音控制命令 |
| 蓝牙遥控 | HC-05 模块，MIT App Inventor 制作 APP |
| 舵机控制 | PCA9685 I²C 驱动，8 路关节运动 |
| 电机驱动 | 履带行走控制 |
| LCD 显示 | 1.3 寸屏幕状态显示 |
| ADC 检测 | 电池电量监测 |
| 眼灯/蜂鸣器 | 状态指示 |

### VC-02 注意事项
- VC-02 SDK 生成的程序只能通过串口发送十六进制数
- 接收缓存为 uint8_t 型，需要做数据转换
- HexChar 函数：将 16 进制 ASCII 码转为实际 16 进制数

### 蓝牙 APP
- 推荐使用 [MIT App Inventor](https://appinventor.mit.edu/) 制作
- 不需要写代码，可视化拖拽式开发

## 预估时间表

| 阶段 | 预估时间 | 备注 |
|------|---------|------|
| 元器件采购 | 1-2 周 | 含等快递 |
| PCB 打样 | 3-5 天 | 嘉创标准交期 |
| 3D 打印 | 1-2 周 | 零件多，周期长 |
| 焊接 | 2-3 天 | 逐模块焊接测试 |
| 清理+组装 | 2-3 天 | 支撑清理最耗时 |
| 软件调试 | 3-5 天 | 各模块逐一验证 |
| **总计** | **约 3-5 周** | 含等待时间 |
