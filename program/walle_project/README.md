# 🤖 梁山派瓦力机器人 — 准备与计划

基于 **GD32F470ZGT6**（梁山派开发板）的 WALL-E 机器人制作指南。

开源地址：https://oshwhub.com/gshaoburuchuan/li-chuang-kai-fa-ban-liang-shan-pai-wa-li-ji-qi-ren

## 项目特点

- 3D 打印外壳（高 33cm，宽 30cm，空壳 2.2kg）
- 支持蓝牙 / LoRa / 2.4G 遥控
- 8 路舵机控制
- 语音交互（VC-02 语音模块）
- 1.3 寸 IPS LCD 显示
- 摄像头实时图传（150 米）
